# Libota website

React + Vite website. See the [main README](../README.md) for how to run, test and deploy the whole project.

```bash
npm install
npm run dev      # development server
npm test         # unit tests (Vitest)
npm run build    # production build in dist/
```

The address of the API comes from `VITE_API_URL` (default `http://localhost:5001/api`). It is baked in when the site is built.
